Entry for the make.fun bounty **One Line, One Laugh**
(`u-plucky-finch-20-one-line-one-laugh-0ffe66ea`).

`main.ts` writes a single funny line of at most 200 characters to
`/output/entry.txt`:

> The photocopier jammed, then printed its own resignation letter.

Run it with Node 22 or later:

```sh
node main.ts
```

The program self-checks the 1–200 character gate (and that the entry is
a single line with no newline) before writing, and writes the entry
with no trailing newline so the gate counts exactly what is on the
line.
